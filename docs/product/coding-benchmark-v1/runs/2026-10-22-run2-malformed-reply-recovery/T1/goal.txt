Compute remote target authorization (Rust). Ensure the remote-execution target (compute serve) enforces the documented credential, revocation and control-plane ownership contract across its HTTP endpoints and durable jobs/sessions. A target must not expose protected operations to unauthenticated callers, let revoked credentials stay effective, or expose one control plane's jobs/sessions to another. The repo documents these guarantees; determine whether the implementation enforces them end to end.
Requirements: read the implementation, docs and tests first. Reproduce at least one concrete defect against the starting commit before changing code. Use the existing authentication/authorization abstractions; no parallel credential system, new daemon, sidecar or credential format. Make every protected endpoint enforce the contract, health/capabilities and job/session operations included. Check revocation and rotation behave as documented, and that one control plane cannot inspect or operate on another's jobs/sessions without leaking information. Preserve existing error semantics, durable state, receipts and authorized requests. Add regression tests through the real HTTP path that fail before the fix and pass after.
Acceptance: missing, malformed, wrong and revoked credentials refused wherever authentication is required; valid credentials work; rotation/revocation as documented; existing remote, job and session tests still pass. No unrelated refactors; do not weaken enforcement or tests; no unsupported security claims in docs. Do not commit or push. Report the defect found, how you reproduced it, changed files, tests and results, and remaining limitations.
